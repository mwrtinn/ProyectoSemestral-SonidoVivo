# Sonido Vivo - Catálogo E-commerce

Sitio web transaccional desarrollado como proyecto semestral para la venta de instrumentos musicales y equipos de audio.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Diseño visual y adaptable.
* **JavaScript:** Lógica del carrito y validación de formularios.
* **Git y GitHub:** Control de versiones en equipo.

## 👥 Equipo y Roles
* **Martín Faúndez:** Páginas de inicio (`index.html`), catálogo (`catalogo.html`) y sus estilos.
* **Vicente Vega:** Página de pedidos (`pedido.html`) y sus estilos.
* **Joaquín Orellana:** Lógica y funciones en JavaScript (`funciones.js`).

## 📂 Estructura del Proyecto
* `index.html`: Página de bienvenida.
* `catalogo.html`: Muestra de productos.
* `pedido.html`: Carrito y checkout.
* `css/style.css`: Estilos de la tienda.
* `js/funciones.js`: Interactividad y almacenamiento.
